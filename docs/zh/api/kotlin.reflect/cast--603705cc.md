## 用途与说明

将给定的 `value` 投递到由此 `KClass` 对象所代表的类。 如果值为 `null` 或不是此类的例子, 则丢弃例外 。

这是一个实验功能, 与 JVM 中 Kotlin. refect. 完全相同。

@see `KClass.isInstance` `KClass.isInstance` @see `KClass.safeCast`

??? note "查看英文原文"

    Casts the given `value` to the class represented by this `KClass` object.
    Throws an exception if the value is `null` or if it is not an instance of this class.
    
    This is an experimental function that behaves as a similar function from kotlin.reflect.full on JVM.
    
    @see `KClass.isInstance`
    @see `KClass.safeCast`

## 用法示例与输出

### 示例 1 · JVM

```kotlin title="示例 1" linenums="1"
@file:OptIn(kotlin.ExperimentalStdlibApi::class, kotlin.ExperimentalUnsignedTypes::class, kotlin.time.ExperimentalTime::class, kotlin.contracts.ExperimentalContracts::class, kotlin.io.path.ExperimentalPathApi::class, kotlin.uuid.ExperimentalUuidApi::class, kotlin.concurrent.atomics.ExperimentalAtomicApi::class, kotlin.io.encoding.ExperimentalEncodingApi::class)

import kotlin.reflect.*
import kotlin.test.*



fun main() {

        fun <T : Any> checkIsInstance(kclass: KClass<T>, value: Any?, expectedResult: Boolean) {
            if (expectedResult) {
                println(kclass.isInstance(value))
                println(value === kclass.safeCast(value))
                println(value === kclass.cast(value))
            } else {
                println(kclass.isInstance(value))
                println(kclass.safeCast(value))
                assertFailsWith<ClassCastException> { kclass.cast(value) }
            }
        }

        val numberClass = Number::class
        checkIsInstance(numberClass, 1, true)
        checkIsInstance(numberClass, 1.0, true)
        checkIsInstance(numberClass, null, false)
        checkIsInstance(numberClass, "42", false)
    
}
```
