# runningFold

`kotlin.collections` · **2.4.21** · Common

本文含经 Kotlin / stdlib 2.4.21 在 **JVM** 上编译运行的代表性示例。

## 用途与说明

返回包含从左向右应用 `operation` 生成的连续累积值的列表, 以及以 `initial` 值开始的当前累积值 。

请注意, `acc` 值已传递到 `operation` 函数,不应变异;否则,它会影响生成列表中的先前值。

@param `operation` 函数,它使用当前累积值和元素,计算下一个累积值。

@sample 样本、采集的样本、采集的采集资料、分类、流动的样本

??? note "查看英文原文"

    Returns a list containing successive accumulation values generated by applying `operation` from left to right
    to each element and current accumulator value that starts with `initial` value.
    
    Note that `acc` value passed to `operation` function should not be mutated;
    otherwise it would affect the previous value in resulting list.
    
    @param `operation` function that takes current accumulator value and an element, and calculates the next accumulator value.
    
    @sample samples.collections.Collections.Aggregates.runningFold

### 示例 1 · JVM

```kotlin title="示例 1" linenums="1"
@file:OptIn(kotlin.ExperimentalStdlibApi::class, kotlin.ExperimentalUnsignedTypes::class, kotlin.time.ExperimentalTime::class, kotlin.contracts.ExperimentalContracts::class, kotlin.io.path.ExperimentalPathApi::class, kotlin.uuid.ExperimentalUuidApi::class, kotlin.concurrent.atomics.ExperimentalAtomicApi::class, kotlin.io.encoding.ExperimentalEncodingApi::class)
import kotlin.math.*



fun main() {
    val strings = listOf("a", "b", "c", "d")
    println(strings.runningFold("s") { acc, string -> acc + string })
    println(strings.runningFoldIndexed("s") { index, acc, string -> acc + string + index })

    println(emptyList<String>().runningFold("s") { _, _ -> "X" })
}
```

```text title="输出"
[s, sa0, sa0b1, sa0b1c2, sa0b1c2d3]
[s]
```
