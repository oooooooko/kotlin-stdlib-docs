# ln1p

`kotlin.math` · **2.4.21** · Common

本文含经 Kotlin / stdlib 2.4.21 在 **JVM** 上编译运行的代表性示例。

## 用途与说明

计算 `ln(x + 1)` 。

此函数可以用于为接近零的`x`产生更精确的结果。

特殊情况:
  - `ln1p(NaN)`是`NaN`
  - `ln1p(x)`是`NaN`何 地`x < -1.0`
  - `ln1p(-1.0)`是`-Inf`
  - `ln1p(+Inf)`是`+Inf`

@see `ln` 函数
@see `expm1` 函数

### 示例 1 · JVM

```kotlin title="示例 1" linenums="1"
@file:OptIn(kotlin.ExperimentalStdlibApi::class, kotlin.ExperimentalUnsignedTypes::class, kotlin.time.ExperimentalTime::class, kotlin.contracts.ExperimentalContracts::class, kotlin.io.path.ExperimentalPathApi::class, kotlin.uuid.ExperimentalUuidApi::class, kotlin.concurrent.atomics.ExperimentalAtomicApi::class, kotlin.io.encoding.ExperimentalEncodingApi::class)
import kotlin.math.*



fun main() {
    // ln1p has better precision for arguments close to zero
    println(ln1p(1e-20) > 0.0)
    println(ln1p(1e-20))
    // compared to adding 1.0 to a value and passing it to ln
    println(ln(1e-20 + 1.0))

    // Special cases
    println(ln1p(Double.NaN))
    println(ln1p(-2.0))
    println(ln1p(-1.0))
    println(ln1p(Double.POSITIVE_INFINITY))
}
```
