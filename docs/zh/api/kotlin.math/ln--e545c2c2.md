## 用途与说明

计算 `x` 的自然对数(基准`E`)。

特殊情况:
  - `ln(NaN)`是`NaN`
- `ln(x)`是`NaN` 当`x < 0.0`时
  - `ln(+Inf)`是`+Inf`
  - `ln(0.0)`是`-Inf`
