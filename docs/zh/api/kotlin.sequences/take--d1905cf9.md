## 用途与说明

返回包含第一批`n`元素的序列。

操作是 _ 中间线 _ 和 _ 无国籍 。

@throws 非法设备,如果`n`为负数,则不在此列。

@sample 样本 采集 采集 变形 采集

??? note "查看英文原文"

    Returns a sequence containing first `n` elements.
    
    The operation is _intermediate_ and _stateless_.
    
    @throws IllegalArgumentException if `n` is negative.
