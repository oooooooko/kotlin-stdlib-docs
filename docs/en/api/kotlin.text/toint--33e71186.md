# toInt

`kotlin.text` · **2.4.21** · Common

Representative examples on this page were compiled and executed on **JVM** with Kotlin / stdlib 2.4.21.

## Description

Parses the string to an `Int` number.

The string must consist of an optional leading `+` or `-` sign and decimal digits (`0-9`),
and fit the valid `Int` value range (within `Int.MIN_VALUE..Int.MAX_VALUE`),
otherwise a `NumberFormatException` will be thrown.

@throws NumberFormatException if the string is not a valid representation of an `Int`.
@sample samples.text.Numbers.toInt

## Usage examples and output

### Example 1 · JVM

```kotlin title="Example 1" linenums="1"
@file:OptIn(kotlin.ExperimentalStdlibApi::class, kotlin.ExperimentalUnsignedTypes::class, kotlin.time.ExperimentalTime::class, kotlin.contracts.ExperimentalContracts::class, kotlin.io.path.ExperimentalPathApi::class, kotlin.uuid.ExperimentalUuidApi::class, kotlin.concurrent.atomics.ExperimentalAtomicApi::class, kotlin.io.encoding.ExperimentalEncodingApi::class)
import kotlin.test.assertFailsWith



fun main() {
    println("0".toInt())
    println("42".toInt())
    println("042".toInt())
    println("-42".toInt())
    // Int.MAX_VALUE
    println("2147483647".toInt())
    // Int overflow
    assertFailsWith<NumberFormatException> { "2147483648".toInt() }
    // 'a' is not a digit
    assertFailsWith<NumberFormatException> { "-1a".toInt() }
    // underscore
    assertFailsWith<NumberFormatException> { "1_000".toInt() }
    // whitespaces
    assertFailsWith<NumberFormatException> { " 1000 ".toInt() }
}
```
