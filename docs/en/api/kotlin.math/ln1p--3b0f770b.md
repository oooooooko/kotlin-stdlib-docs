# ln1p

`kotlin.math` · **2.4.21** · Common

Representative examples on this page were compiled and executed on **JVM** with Kotlin / stdlib 2.4.21.

## Description

Computes `ln(x + 1)`.

This function can be implemented to produce more precise result for `x` near zero.

Special cases:
  - `ln1p(NaN)` is `NaN`
  - `ln1p(x)` is `NaN` where `x < -1.0`
  - `ln1p(-1.0)` is `-Inf`
  - `ln1p(+Inf)` is `+Inf`

@see `ln` function
@see `expm1` function

import kotlin.math.*



fun main() {
    // ln1p has better precision for arguments close to zero
    println(ln1p(1e-20) > 0.0)
    println(ln1p(1e-20))
    // compared to adding 1.0 to a value and passing it to ln
    println(ln(1e-20 + 1.0))

    // Special cases
    println(ln1p(Double.NaN))
    println(ln1p(-2.0))
    println(ln1p(-1.0))
    println(ln1p(Double.POSITIVE_INFINITY))
}
