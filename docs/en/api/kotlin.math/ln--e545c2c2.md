# ln

`kotlin.math` · **2.4.21** · Common

Representative examples on this page were compiled and executed on **JVM** with Kotlin / stdlib 2.4.21.

## Description

Computes the natural logarithm (base `E`) of the value `x`.

Special cases:
  - `ln(NaN)` is `NaN`
  - `ln(x)` is `NaN` when `x < 0.0`
  - `ln(+Inf)` is `+Inf`
  - `ln(0.0)` is `-Inf`
