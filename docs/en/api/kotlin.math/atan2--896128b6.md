# atan2

`kotlin.math` · **2.4.21** · Common

Representative examples on this page were compiled and executed on **JVM** with Kotlin / stdlib 2.4.21.

## Description

Returns the angle `theta` of the polar coordinates `(r, theta)` that correspond
to the rectangular coordinates `(x, y)` by computing the arc tangent of the value `y` / `x`;
the returned value is an angle in the range from `-PI` to `PI` radians.

In other words, this function returns an angle in radians between the positive x-axis and
a ray from the origin (`(0, 0)`) to the point `(x, y)` confined to the interval `(-π, π]`.

The `r` component (the distance) of the polar coordinates `(r, theta)` could be calculated as `hypot(x, y)`.

Special cases:
  - `atan2(0.0, 0.0)` is `0.0`
  - `atan2(0.0, x)` is  `0.0` for `x > 0` and `PI` for `x < 0`
  - `atan2(-0.0, x)` is `-0.0` for `x > 0` and `-PI` for `x < 0`
  - `atan2(y, +Inf)` is `0.0` for `0 < y < +Inf` and `-0.0` for `-Inf < y < 0`
  - `atan2(y, -Inf)` is `PI` for `0 < y < +Inf` and `-PI` for `-Inf < y < 0`
  - `atan2(y, 0.0)` is `PI/2` for `y > 0` and `-PI/2` for `y < 0`
  - `atan2(+Inf, x)` is `PI/2` for finite `x`
  - `atan2(-Inf, x)` is `-PI/2` for finite `x`
  - `atan2(NaN, x)` and `atan2(y, NaN)` is `NaN`

@see hypot function.

## Usage examples and output

### Example 1 · JVM

```kotlin title="Example 1" linenums="1"
@file:OptIn(kotlin.ExperimentalStdlibApi::class, kotlin.ExperimentalUnsignedTypes::class, kotlin.time.ExperimentalTime::class, kotlin.contracts.ExperimentalContracts::class, kotlin.io.path.ExperimentalPathApi::class, kotlin.uuid.ExperimentalUuidApi::class, kotlin.concurrent.atomics.ExperimentalAtomicApi::class, kotlin.io.encoding.ExperimentalEncodingApi::class)
import kotlin.math.*



fun main() {
    val epsilon = 1e-10
    fun Double.toDegrees(): Double = this * 180.0 / PI

    println(atan2(y = 0.0, x = 0.0))

    // Results may not be exact, so we're only checking that they are within epsilon from the expected value
    println((atan2(y = 1.0, x = 0.0) - PI / 2).absoluteValue < epsilon)
    println(atan2(y = 1.0, x = 0.0).toDegrees())

    println((atan2(y = 0.0, x = -1.0) - PI).absoluteValue < epsilon)
    println(atan2(y = 0.0, x = -1.0).toDegrees())

    println((atan2(y = -1.0, x = 0.0) - (-PI / 2)).absoluteValue < epsilon)
    println(atan2(y = -1.0, x = 0.0).toDegrees())

    // special cases (some of them)
    println(atan2(y = Double.NaN, x = 0.5))
    println(atan2(y = 0.5, x = Double.NaN))
    println(atan2(y = -0.0, x = 100500.0))
    println(atan2(y = 0.0, x = Double.POSITIVE_INFINITY))
    println(atan2(y = Double.POSITIVE_INFINITY, x = 100500.0).toDegrees())
}
```
